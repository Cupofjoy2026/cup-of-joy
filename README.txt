CUP OF JOY — защищённый сайт

Структура:
- index.html — публичный сайт
- admin/ — закрытая админка Decap CMS
- content/site.json — данные сайта

Публикация: подключить папку к GitHub + Netlify, затем включить Netlify Identity и Git Gateway.
В Identity выбрать Invite only и пригласить только свой e-mail. После этого редактирование доступно через /admin/.
